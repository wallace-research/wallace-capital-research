This page tracks my recommendations against subsequent market returns

The table below records my original recommendation, subsequent total returns over various time horizons, and if my recommendation was accurate. The return columns are updated monthly to reassess. To keep things relatively simple, I use the S&P 500's one-year total return as my benchmark. As you can see below, three columns illustrate the efficacy of my prediction. First, the analyzed stock's return over multiple time periods. Second, SPY's return. Last, the relative return of the analyzed stock's return. A stock that generates lucid positive alpha, or outperforms SPY, is considered a good recommendation if I rated it as a Buy, a neutral recommendation if rated as a Hold, and a poor recommendation if rated as a Sell. Meanwhile, I deem a stock that rivals SPY or slightly underperforms it to be a neutral recommendation as a Buy, a good recommendation as a Hold, and a poor rating as a Sell. Last, I view stocks that substantially underperform or have a negative return over one year to be a poor recommendation as a Buy, a neutral recommendation as a Hold, and a good recommendation as a Sell. While there are much more nuances that could be captured here, such as CAPM, Sharpe ratios, and complicated factor models, I have elected to use this methodology for brevity and ease of viewing.
